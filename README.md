📌 1. Project Overview

SkillTrack is an AI-powered longitudinal skilling-outcomes and employment intelligence platform designed to connect skill development, training, certification, placement, employment verification, retention, and livelihood progression.

Traditional skilling systems frequently capture enrollment, attendance, assessments, and certifications. However, reliable information about what happens after training often remains fragmented.

- Did the trainee actually secure employment?
- Did the candidate join the organization?
- Is the employment relevant to the training received?
- Is the candidate still employed after 3, 6, or 12 months?
- Has the candidate's income improved?
- Did the training lead to self-employment or an apprenticeship?
- What caused non-placement or employment attrition?

SkillTrack addresses this gap by moving beyond training and placement statistics towards measurable, evidence-oriented, long-term employment outcomes.

Our platform connects candidates, recruiters, training centers, placement officers, employers, and organizational administrators through a unified intelligence ecosystem.

Our Vision

«Measure not only how many people are trained and placed, but how many secure employment, improve their livelihoods, and remain employed.»

Understanding the Problem

The official challenge highlights the difficulty of obtaining reliable, consistent, and long-term employment information after training.

Major challenges include:

- Incomplete employment and self-employment information.
- Changes in trainee phone numbers and locations.
- Inconsistent employer reporting.
- Different identifiers across training programs.
- Limited employment verification.
- Missing wage progression information.
- Lack of long-term retention records.
- Difficulty identifying skill gaps and non-placement reasons.
- Limited comparison of training providers and program effectiveness.

Our Approach

SkillTrack proposes a consent-based, privacy-conscious system that connects training records with placement and employment signals, conducts automated and assisted follow-ups, validates employment information, and generates actionable impact analytics.

🔐 9. Privacy, Consent & Data Governance

SkillTrack emphasizes credible and privacy-conscious outcome tracking.

Core Principles

- Consent-based trainee records.
- Minimal and purpose-specific data collection.
- Secure authentication.
- Role-based access.
- Organization-level data isolation.
- Supabase Row Level Security.
- Controlled access to employment information.
- Verification evidence and audit history.
- Appropriate data retention and deletion practices.

Employment Evidence Classification

Status| Meaning
Unknown| No reliable outcome information available
Self-Reported| Information submitted by the candidate
Assessment-Supported| Supported by available assessments or records
Verified| Confirmed through an authorized verification process

A self-reported employment claim must not automatically be treated as independently verified employment.

⚙️ 13. Installation & Local Setup

Prerequisites

- Node.js
- npm
- Git
- Supabase project
- Google Gemini API key for enabled AI features

Step 1: Clone the Repository

git clone https://github.com/suresh31-ch/SkillTrack-SIH26135.git

Step 2: Navigate to the Project

cd SkillTrack-SIH26135

Step 3: Install Dependencies

npm install

Step 4: Configure Environment Variables

Create a ".env.local" file in the project root.

GEMINI_API_KEY=your_gemini_api_key
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key

Use only the variables required by the current project configuration. Never expose private credentials or Supabase service-role keys in frontend code or public repositories.

Step 5: Start the Development Server

npm run dev

Step 6: Open the Application

Use the local URL displayed in your terminal.
